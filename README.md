# Current work

**[Pwsh](https://github.com/MansfieldPlumbing/Pwsh)** — PowerShell on Android:
CoreCLR and System.Management.Automation in-process, built by one PowerShell
script from pinned, hash-verified inputs.

**[Kokoro-Hexagon](https://github.com/MansfieldPlumbing/Kokoro-Hexagon)** —
Kokoro-82M text-to-speech for Qualcomm Hexagon, authored in PowerShell. In
development.

**[V340L-Emancipated](https://github.com/MansfieldPlumbing/V340L-Emancipated)**
— DirectML and D3D12 compute for the AMD Radeon Pro V340L on Windows, from
PowerShell with no build step.

**[QuickPS](https://github.com/MansfieldPlumbing/QuickPS)** — PowerShell
bindings for Win32, DXGI, D3D12, DirectComposition, WASAPI and Media
Foundation.

**[Kinetics](https://github.com/MansfieldPlumbing/Kinetics)** — Audio-synced
kinetic typography across a continuous spatial graph.
[Live](https://mansfieldplumbing.github.io/kinetics/).
