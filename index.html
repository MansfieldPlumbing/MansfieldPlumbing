v340l-windows-enablement

AMD Radeon Pro V340L MxGPU activation on Windows via Switchtec daemon + KMDF mapper. Turns $50 decommissioned Stadia cards into usable 8GB inference silicon. Primary-source discipline, zero-brick guarantee.

Hardware Enablement

DirectPort-SDK

Zero-copy inter-process GPU sharing (D3D11/12 ↔ CUDA) via NT handles + hardware fence sync. ~170ns consumer unblock latency. No polling, no copies, just PCIe crossbar speed.

Low-Latency IPC

RIFE_TRT

Native TensorRT frame interpolation. 2x/4x/8x at ~28ms/frame-pair on RTX 3090. C# NativeAOT + async CUDA, Media Foundation decode, zero-copy in-memory pipeline. No Python runtime.

Real-Time Inference

VirtuaCam

Modern Media Foundation virtual camera with DirectPort zero-copy broker. Multi-producer compositing, WASAPI loopback, system-registered output. Production-grade, not a hobby plugin.

Virtual Production

Demucs_v4_TRT

HTDemucs v4 on TensorRT. STFT/ISTFT internalized for full kernel fusion. ~5 seconds end-to-end on RTX 3090 for a 3-minute track. Published on Hugging Face.

Audio Separation

Depth_TRT

Depth Anything V2 on TensorRT. C# NativeAOT orchestrator with unsafe Parallel.For + LockBits for real-time CHW tensor transposition. ImageNet normalization baked into unmanaged C++ bridge.
